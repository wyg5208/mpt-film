# 聊天起始卡「工作流 + 风格」双列紧凑改版

## Summary

改造共享组件 `WorkflowCards`（web `ChatPanel.tsx` 与桌面 `App.tsx` blank 分支同时挂载），把空态聊天从「单列 5 卡 + 三行头部」改为：

- **一行头部**：LOGO + 标题 + 提示语（截断，全文进 title 属性）。
- **工作流区**：固定两列紧凑卡（类目色图标 + 标题 + 徽章 + 两行 blurb），点击展开的步骤管线/brief 表单/启动按钮**原样保留**，展开时该卡跨满两列。
- **风格与技能区**：两列更轻量的 chip 卡（技能专属色相图标 + 标题 + kind 徽章），镜像 @ 提及的可用技能集合（约 10–11 个，5 style + 6 workflow），点击**只填充不发送**——桌面插入 Lexical pill，web 填充含原始技能名的 kickoff 文本。
- 日常用语折叠行、附件行、engine 广告门控全部不动。

数据走现成 `GET /api/skills` + `watchSkills`（缓存 + `SKILLS_CHANGED` 失效），双端同窗同源可用。**不改服务端、不改 IPC、不改 api.ts、不改 ChatPanel.tsx**。

仓库根：`d:\python_projects\moneyprintturbo\opensources\changovideo`（下文路径相对此根）。

## 工作流卡片 vs @技能：消歧设计（调研结论）

**事实核实**（workflow-catalog.mjs / skills/*/changovideo.json / App.tsx mentionProviders）：
- @ 列表与卡片是**两类不同实体，功能零重叠**。5 条工作流卡是管线模板（idea-motion 等），本身**不在 @ 列表里**；@ 里的 11 个官方技能 = 6 个 kind:'workflow'（视频复刻/长视频转短视频/录屏演示/高级MG动画/小窗人物口播/影片收尾总结）+ 5 个 kind:'style'（手绘白板/复古胶片/动态歌词/发布会/剪贴风）。
- **点击工作流卡**：展开步骤管线 → 启动 = 把 openmotion-* 指南技能安装进项目 + 填充结构化 kickoff（工作流名+有序步骤+技能+想法+简报事实），agent 按多步管线执行。
- **@ 选技能（含「玩法」类）**：插入 pill，发送时该技能 SKILL.md 全文附在消息后，agent 读取并跟随这**单一技能的做法**；无安装、无管线、无简报表单。
- 唯一交集：卡片启动后安装的 openmotion-* 指南会以项目技能身份出现在 @ 中——那是卡片自己的技能集，不是重复入口。
- **困惑根源是命名**：「工作流」一词同时指卡片分区与技能 kind（kind:'workflow'）。若技能徽章也叫「工作流」，用户会误以为上下两区是同一物。

**消歧决策**（不合并入口、不改 @ 列表）：
1. 技能 kind 徽章措辞：style→「风格」、workflow→「**玩法**」（绝不叫「工作流」）；分区标题「工作流」vs「风格与技能」。
2. 技能区标题下加一行常驻消歧提示（新 i18n 键 `workflow.stylesHint`，可被设置关闭）：zh「技能随消息附上做法说明，点一下即填入；工作流是展开即启动的多步管线。」en「A skill rides your message as its method; a workflow is a multi-step pipeline you expand and start.」
3. 工作流卡 hover/title 保留「N 步 · M 技能」meta；技能 chip hover 显示 summary——两类入口的说明各自到位。
4. DEMO 页内置「对比说明」抽屉，用表格呈现上述差异供用户确认。

## 视觉与交互规格（决策已定）

**容器与头部**
- 外层 `max-w-[400px]` → `max-w-[640px]`（实际宽度受宿主 pane 约束，web 外层 max-w-720 已容纳）。
- 头部 `flex items-center gap-2.5`：logo（宿主传入的 BrandLogo 26px 不变）+ `h2 text-[15px] font-semibold whitespace-nowrap`（现 `workflow.title` 文案不变）+ `p flex-1 min-w-0 truncate text-[12px] text-[var(--text-muted)]`（现 `workflow.hint` 文案不变，`title` 属性挂全文，`max-[420px]:hidden`）。DOM 顺序 logo→h2→p 不变。

**分区小标题**：`text-[11px] font-medium tracking-wide text-[var(--text-faint)]`，工作流区「工作流」、技能区「风格与技能」+ 计数；技能区标题行右侧放「展开全部/收起」按钮（超 cap 时）。技能区标题下常驻一行消歧提示 `workflow.stylesHint`（`text-[11px] text-[var(--text-faint)]`，见消歧设计节）。

**工作流卡（收起态，紧凑化）**
- `ul` 改 `grid grid-cols-2 gap-2 max-[360px]:grid-cols-1`；`li` 在 `open===wf.id` 时加 `col-span-2 max-[360px]:col-span-1`。
- 卡片按钮：`px-3 py-2.5`，图标块 h-7 w-7（Icon 15px），类目色 `color-mix` 底沿用现 `CAT_COLOR`；标题 `text-[13px] truncate`；类目徽章与 engineBadge 保留；blurb `text-[11.5px] line-clamp-2`；`cardMeta` 行从收起态移除（改挂按钮 title 提示）；ChevronDown 保留。
- **展开面板 DOM 一字不动**（ol>li 步骤、WorkflowBriefFields/idea input、Start workflow/Start making、draftBrief/openBrief、AdBriefDialog、changovideo-rise 动画），仍在同一 `li` 内。

**风格/技能 chip（与工作流卡明确区分）**
- 容器用 **`div`**（不用 ul）：`grid grid-cols-2 gap-1.5`；**不带 aria-hidden**。
- 每 chip 为 `button`（**绝不带 aria-expanded**）：`flex items-center gap-2 rounded-lg border border-transparent bg-[var(--bg-hover)] px-2.5 py-2 text-left transition hover:border-[var(--border)] hover:bg-[var(--surface)]`，高度约为工作流卡 2/3。
- 图标块 h-6 w-6 rounded-md，色相来自技能 icon id 的 `SKILL_ICONS`/`SKILL_HUES` 映射（从 `studio/ui/src/components/SkillsLibrary.tsx` L473-478 复制到 WorkflowCards.tsx 私有常量，加同源注释；底色 `color-mix(in srgb, hsl(H 70% 55%) 14%, transparent)`）。**不用 cover 原图**（11 张共 1.34MB 无缩放管线）。
- 标题 `text-[12.5px] truncate`（shown.title 按当前语言）；kind 微徽章 9.5px：style→「风格」`var(--tl-voice)`，workflow→「玩法」`var(--tl-accent)`；summary 挂 button title 作 hover 说明。
- 排序与 @ 一致：`(order??999)` 升序 → `name.localeCompare`（复用 SkillsLibrary.byOrder 语义，在 lib 重写为纯函数）。
- 默认 cap 12；超出显示「展开全部 {count} 个」，就地展开后列表 `max-h-[320px] overflow-y-auto`。agent 自有技能不进网格（仍走 @）。
- 点击反馈：桌面 composer 立即出现技能 pill；web textarea 立即出现 kickoff 文本——均不发送。

**降级**：技能列表 null/空/请求失败 → 整个技能区静默隐藏（sourcesApi 失败自动回退缓存），工作流区不受影响；首帧用 `seenSkills(projectId)` 缓存直画。窄窗 <360px 工作流退单列，技能区保持两列。

## Risks & Mitigations
- **REST 与桌面 IPC 两份技能列表短暂不一致** → 同窗 SKILLS_CHANGED 同时触发 watchSkills 与 reloadSkills，秒级收敛；网格只收 changovideo 源，与 @ 的 agent 自有部分解耦。
- **技能数增长撑爆网格** → cap 12 + 就地展开限高滚动；agent 自有上百技能仍走 @（limit:Infinity 带搜索）。
- **桌面 blank 裁顶** → my-auto 修复列为必改项，验收第 5 步专测。
- **web 填充文本 agent 不认技能** → kickoff 强制含原始 name，纯逻辑测试断言。
- **展开跨列引起网格回流跳动** → 单 open 状态互斥 + 现 changovideo-rise 动画掩盖。
- **新键漏语言** → parity 测试自动拦截；五份一次写齐。

- **新增 GET /api/skills 路由 / api.ts 方法**：路由与前端封装均已存在（server.mjs L710、project-sources.ts L120），无需新增。
- **cover.jpg 缩略图卡面**：11 张原图 1.34MB、服务端无缩放管线，紧凑卡加载即原图；改用零网络成本的图标色相块（与 SkillsLibrary 视觉语言同源），cover 留作后续 hover 浮层可选。
