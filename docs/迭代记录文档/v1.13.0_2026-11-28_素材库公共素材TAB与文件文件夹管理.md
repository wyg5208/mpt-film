# 2026-11-28 迭代记录：素材库公共素材 TAB 与文件/文件夹管理

本轮为**新增功能**驱动型迭代，按版本政策升 **minor：`v1.12.1 → v1.13.0`**。核心结论：在「素材库」页顶部新增「公共素材」TAB，提供一个跨所有项目共享的文档空间（`storage/material_docs`），任意任务都能浏览并引用其中的内容；同时在「任务素材」「公共素材」两个 TAB 内支持通过 UI 直接对 TXT/MD 文件与空文件夹进行创建/编辑/删除。后端为**全新增文件**（服务 + REST 控制器 + 路由挂载），不改动既有渲染流水线；前端新增可复用文件管理器组件与 API 封装，改造素材库页承载双 TAB。安全纪律复用既有 `material_upload` / `file_security` 同一套路径与名称校验。

> **仓库边界**：本轮全部代码变更落在外层 ChangoFilm（Python）仓库，不涉及嵌套的 ChangoVideo / sau 子仓库。

## 2. 变更清单

### 2.1 后端（新增文件，不改动既有渲染流水线）

- **新增 `app/services/material_docs.py`**：公共（`storage/material_docs`）/ 任务（`storage/tasks/{task_id}`）两作用域内的 TXT/MD 文件与空文件夹 CRUD。安全纪律对齐 `material_upload` / `file_security`：
  - **逐级名称清洗**（`_validate_name`）：复用 `material_upload` 的字符级黑名单 `_UNSAFE_FILENAME_CHARACTERS`、`_WINDOWS_INVALID_FILENAME_CHARS`、`_WINDOWS_RESERVED_FILENAMES`，拒绝路径分隔符（`/`、`\`）、`.`/`..`、控制符与双向文本字符、Windows 非法字符与保留设备名（`CON`/`PRN`/`AUX`/`NUL`/`COM*`/`LPT*`，扩展名前的段也按设备名校验）、点前缀隐藏名，长度上限 127。
  - **真实路径校验**：组装后经 `file_security.resolve_path_within_directory` 校验，阻断 `..` 穿越与符号链接逃逸；读写只允许普通文件 / 真实目录，`_require_type` 显式拒绝链接与特殊文件类型。
  - **原子落盘**：`write_text` 文本写入上限 `MAX_TEXT_FILE_BYTES = 1 MiB`，同目录 `.material-doc-*.part` 临时文件 + `flush` + `os.fsync` + `os.replace` 原子替换，异常时清理临时文件。
  - **扩展名白名单与容错读**：仅允许 `.txt`/`.md`（`TEXT_EXTENSIONS`），无后缀经 `normalize_text_name` 补 `.txt`；读取按 `encoding="utf-8", errors="replace"` 容错解码。
  - **异常分层**：`MaterialDocError`(400) / `MaterialDocNotFound`(404) / `MaterialDocConflict`(409)，`status_code` 随类携带供控制器翻译。
  - **列表防护**：`list_tree` 递归但有 `MAX_TREE_DEPTH = 8`、`MAX_LISTING_ENTRIES = 2000` 上限（超限置 `truncated`），跳过链接项与点前缀隐藏名。
  - **更新语义**：`write_text` 同名已存在（普通文件）走更新，返回 `created=False`；目标为目录/特殊类型则 409。

- **新增 `app/controllers/v1/materials.py`**：REST 端点，`scope=public|task`，路由依赖统一 `verify_token`：
  - `GET /api/v1/materials/tree`、`GET/POST/PUT/DELETE /api/v1/materials/file`、`POST/DELETE /api/v1/materials/folder`；
  - 服务层异常经 `_fail` 翻译成 `HttpException`（保留稳定状态码，附 `request_id`）；
  - `tree` 响应**刻意不回传服务器绝对路径 `root`**，只返回相对项 `items` + `truncated`（`get_material_tree` 中对 `data["root"]` 做了屏蔽）。

- **`app/router.py`**：`from app.controllers.v1 import (...)` 增加 `materials`，并在 `plans.router` 之后 `root_api_router.include_router(materials.router)`（附中文注释）。

### 2.2 前端

- **新增 `frontend/src/features/library/useMaterialDocs.ts`**：`materialDocs` API 封装（`tree`/`read`/`createFile`/`updateFile`/`deleteFile`/`createFolder`/`deleteFolder`），每次调用携带 `scope`（`task` 时附 `task_id`）；`childrenOf(items, cwd)` 由后端返回的扁平树过滤单层直接子项，目录优先、`localeCompare(sensitivity:"base")` 大小写无关排序，对齐后端列出意图。

- **新增 `frontend/src/features/library/FileManager.tsx`**：可复用文件管理器组件（`scope`/`taskId` props）：
  - 单层浏览 + 面包屑（`cwd` 为当前文件夹相对路径，`""` 为作用域根），根面包屑按作用域显示 `Public Material Root` / `Task Material Root`；
  - 新建 TXT/MD：内联名称输入 + `textarea` 内容编辑器（`mode:"new-file"`）；编辑：先 `materialDocs.read` 读入内容到 `textarea` 再 `updateFile` 保存；
  - 删除文件 / 删除空文件夹均用 `window.confirm` 二次确认；写操作成功后 `invalidateQueries(['material-tree', scope, taskId])` 重新拉取树；`scope="task"` 时页面以 `key={taskId}` remount 以重置 `cwd`。

- **改造 `frontend/src/features/library/MaterialsLibraryPage.tsx`**：顶部新增 `.tabs`（`data-testid="materials-tabs"`）两个 TAB：
  - 「任务素材」：保留原有任务选择器 + 产物分组浏览，并在下方追加该任务目录内的 `FileManager`（`scope="task"`，`key={effectiveId}`，`Material Docs Title`/`Hint` 小节标题）；
  - 「公共素材」：展示共享文档空间 `FileManager`（`scope="public"`，附 `Public Materials Hint`）。

- **`frontend/src/theme/brand.css`**：追加 `.material-tab-panel`、`.file-manager`、`.fm-*`（`fm-bar`/`fm-crumbs`/`fm-crumb`/`fm-actions`/`fm-inline`/`fm-editor`/`fm-textarea`/`fm-list`/`fm-row`/`fm-name`/`fm-dir`/`fm-size` 等）一套样式块。
