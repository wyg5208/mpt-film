### 2.2 ChangoVideo 子仓库（`opensources/changovideo`，随 fork `v0.18.1` 发布）

- **`scripts/verify-changelog.mjs`**（新增）：离线 bump 后的字节级校验门禁——对比 bump 前 blob（`execFileSync git show` 取 Buffer）与当前文件，U+FFFD 计数必须相等、em-dash 计数不得减少、版本头必须存在；失败退出码 1。
- **两个 agent 文档**：`iteration-doc.md` §3 增补"离线 prepend 会静默损坏历史非 ASCII"条目（v0.16.0 实证 + 完整修复模式）；`version-release.md` §4 新增第 5 步与约束条件——含 CHANGELOG.md 变更的推送前必须通过校验。
- **三份 CHANGELOG 头部**：H1 更正为 `# changovideo` / `# @changovideo/desktop` / `# @changovideo/shared`，H1 下新增纯 ASCII 互链注记（声明与外层版本体系独立）。
