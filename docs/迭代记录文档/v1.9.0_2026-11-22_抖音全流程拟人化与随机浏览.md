# 2026-11-22 迭代记录（v1.9.0）：抖音全流程拟人化与随机浏览

本轮迭代为功能驱动型：用户两次提醒"要加入拟人化操作，包括适当的随机浏览"。此前抖音
自动发布仅有上传前预热浏览 + 等待轮鼠标微动作，标题仍是瞬时 `.fill()`、声明/合集/发布
全部原生点击、发布后秒退出——会话形状仍高度机械。本轮把小红书拟人层的社区共识原语
抽取为平台中立的 `uploader/humanize_core.py`，新增抖音拟人层并全流程接线：逐字符打字、
三阶贝塞尔鼠标点击、步骤间钟形随机停顿，以及**三个随机浏览场景**（上传前预热 /
等待期当前页微动作 / 发布后管理页浏览），打散"打开即上传→秒发布→秒退出"的机器行为
特征。任何拟人步骤异常均自动回退原生行为，绝不因拟人层失败中断发布。

版本号按"每次迭代必升版"政策由 `1.8.1` 升至 **`1.9.0`**（minor：新增面向用户的
抗风控行为层功能）。本文档全部代码符号、环境变量开关、测试数量与干跑数据均于当日
Grep/代码/测试核实。

## 1. 任务目标

| # | 场景 | 迭代前现状 | 目标 |
|---|------|-----------|------|
| 1 | 标题/描述/话题输入 | 标题瞬时 `title_input.fill()`，描述/话题 keyboard.type 整段输入 | 贝塞尔点击聚焦 + 全选清空 + 逐字符打字（标点/思考停顿） |
| 2 | 声明/合集/发布点击 | 全部原生 `locator.click()`，鼠标瞬移 | 三阶贝塞尔轨迹 + 元素内随机落点 + 随机按压时长 |
| 3 | 步骤间节奏 | 固定 `wait_for_timeout` | 钟形分布随机停顿（解析完/声明后/归集后/封面后） |
| 4 | 上传/解析等待期 | 表单等待轮有鼠标微动作，上传/解析等待轮长时间静止 | `idle_browse` 当前页移动/滚动/偶尔回看/停留（**绝不导航**） |
| 5 | 发布后收尾 | 跳管理页后直接回写 cookie、关浏览器（"发布→秒退出"） | `post_publish_browse` 滚动作品列表后再收工 |
| 6 | 原语复用 | 拟人原语内嵌在小红书 humanize.py，抖音无法复用 | 抽到平台中立 `humanize_core.py`，两平台共用且保住既有测试 patch 契约 |

设计纪律（贯穿全部接线）：
- **可靠性优先**：拟人层任何异常回退原生行为；发布按钮回退保留 `force=True`；
  救援路径 `_recover_stuck_form` **保持原生点击**（速度与可靠性优先，测试守卫禁拟人）。
- **等待期绝不导航**：`idle_browse` 只在当前页动作——离开上传页会丢上传进度。

## 2. 变更清单

### 2.1 平台中立拟人原语（子仓库新增：`uploader/humanize_core.py`，126 行）

从小红书拟人层抽取的社区共识实现（xiaohongshu-mcp v2.1.1 / UM7lab fork），供小红书、
抖音共用；各平台模块自带环境变量开关与 logger：

- `env_enabled(var_name, default="1")`：环境变量开关，`0/false/no/off` 视为关闭，缺省开启。
- `bell_delay(min_s, max_s)` / `pause(...)`：近似钟形分布（两个均匀随机取均值），
  操作间随机停顿，不用固定 sleep。
- `type_text(page, text, ...)`：逐字符输入，字符间隔随机（默认 0.05–0.18s），
  标点/空格（`，。！？；：、,.!?;: `）额外停 0.15–0.5s，3% 概率思考停顿 0.6–1.5s；
  关开关时回退整段 `keyboard.type`。
- `bezier(...)` / `click(page, locator, ...)`：三阶贝塞尔轨迹（smoothstep 缓入缓出 +
  ±1.5px 微抖动，12–24 步）+ 元素内随机落点（边距 20% 上限 6px）+ 随机按压时长
  （0.05–0.16s）；bounding box 缺失/过小或任何一步异常回退
  `locator.click(**fallback_kwargs)`（抖音发布等场景由调用方传 `force=True`）。
- `browse(page, url, logger, ...)`：打开目标页、随机滚动 2–4 屏、屏间停留 0.8–2.2s；
  全程容错，失败只记 debug 日志。

### 2.3 抖音拟人层（子仓库新增：`uploader/douyin_uploader/humanize.py`，99 行）

开关：`SAU_DOUYIN_HUMANIZE=0` 关闭行为拟人（延迟/打字/点击/等待期微动作）；
`SAU_DOUYIN_WARMUP=0` 关闭上传前预热与发布后随机浏览。包装函数
`human_pause` / `human_type` / `human_click`（支持 `fallback_kwargs`）委托 core，
另提供三个抖音浏览场景：

- `warmup_browse(page)`：上传前逛创作者首页
  `https://creator.douyin.com/creator-micro/home`，分段滚动几屏（core.browse，全程容错）。
- `idle_browse(page)`：上传/解析等待期随机浏览微动作——移动鼠标、60% 概率下滚
  120–420px（其中 40% 概率再回滚 60–200px，像真人回头核对）、30% 概率停留阅读
  0.8–2.5s。**只在当前页动作，绝不导航**；全程容错（异常静默 pass）。
- `post_publish_browse(page)`：发布后在内容管理页停留 1.0–2.5s、随机滚动作品列表
  2–4 屏再收工；失败只记 debug 日志，不影响发布结果与 cookie 回写。

### 2.4 抖音 main.py 全流程接线（子仓库修改：`uploader/douyin_uploader/main.py`）

- **标题**（L640–644）：`human_click` 贝塞尔点击聚焦 → `Control+KeyA` / `Delete`
  全选清空 → `human_type(title[:30], min_gap=0.04, max_gap=0.12)` 逐字打字，替代瞬时
  `fill`；**保留 `input_value` 落地核验与 3 轮折叠重填**（v1.8.1 防御纵深不变）。
- **描述/话题**（L660–673）：描述编辑器 `human_click` 聚焦 + 全选清空 + `human_type`
  逐字；每个话题 `human_type(" #" + tag)` + Space 确认 + `human_pause(0.3, 0.9)`
  话题间挑选停顿；Escape 收起话题下拉后 `human_pause(0.5, 1.5)` 再走上传/解析核验。
- **自主声明**（L789/L811/L825）：入口、单选项、确定按钮均 `human_click`
  （`fallback_kwargs={"timeout": 6000}`），异常再兜底 `_native_click`。
- **合集归集**（L997/L1015）：`apply_collection` 的下拉触发器与目标选项均 `human_click`
  （`fallback_kwargs={"timeout": 5000}`），异常回退清浮层 + `_native_click`。
- **发布按钮**（L1446）：`human_click(page, publish_button,
  fallback_kwargs={"force": True})`——抖音自定义组件常需 force 兜底，回退保留。
- **步骤间钟形停顿**：解析完成后 `human_pause(0.6, 1.8)`（L1379）、声明后
  `human_pause(0.5, 1.5)`（L1391）、归集后 `human_pause(0.5, 1.5)`（L1396）、
  封面后 `human_pause(0.6, 1.8)`（L1400）。
- **等待轮随机浏览**：表单等待轮 `idle_browse`（L632）；上传等待轮 35% 概率
  `idle_browse`（L1355–1356，`random.random() < 0.35`）；解析等待轮每轮 `idle_browse`
  （L1376）。
- **预热接线**：模块级 `_warmup_creator_home` 委托 `warmup_browse`（L92），
  `_upload_flow` 进上传页前调用（L1269）。
- **发布后收尾**（L1460–1472）：列表核验新作品标题（15s，看不到仅警告）→
  `post_publish_browse(page)`（L1469）→ `context.storage_state` 回写 cookie（L1471）。
- **救援路径不拟人**：`_recover_stuck_form`（L95 起）保持原生点击——可靠性与速度
  优先，`test_recovery_path_stays_native_for_speed` 守卫禁拟人。
