# 2026-11-20 迭代记录（v1.6.0）：脚本方案专业模式与本地 AI 短剧系列 Demo

本轮迭代针对"视频规划是黑盒"的痛点（文案→关键词→素材→盲切拼接无段落级语义绑定，
成片各段互不关联、首尾帧不衔接），交付**脚本方案（ScriptPlan）专业模式**的完整解决方案
文档与可交互 Demo；并按用户补充目标升级为**低成本 AI 短剧系列**创作方案——充分整合本机
已部署的 ComfyUI（MiniMax H3 FL2V 首尾帧视频大模型 + turbo LoRA + IPAdapter）、comfy-mini、
ACE-Step 音乐大模型、Ollama 本地编剧（llama.cpp 列为开放项），UI 大胆修订为
**简单/专业双轨模式 + 创作向导/脚本方案/系列管理三个新页**。沿用三列重构迭代确立的
doc+demo 模式：**本轮不修改生产逻辑代码**，生产实施按方案文档 §7 批次 B2–B8 另行启动。

版本号按"每次迭代必升版"政策由 `1.5.0` 升至 **`1.6.0`**（minor：新增功能）。

## 1. 任务目标

| # | 目标 | 驱动来源 |
|---|------|---------|
| 1 | 脚本方案成为一等公民产物：可见/可编辑/可锁定/可导出的 JSON 分镜脚本，位于文案与生成之间 | 用户痛点（规划黑盒、段间无关联、首尾帧不衔接） |
| 2 | 分镜故事板专业模式：时间线标尺 + 场景卡 + 衔接连接器 + 关键帧对预览抽屉 + 时长仪表 | 用户需求（视频长度/段落/脚本/字幕/BGM/关联/关键帧显式输出） |
| 3 | 低成本 AI 短剧系列：Series→Episode→ScriptPlan→Scene 层级 + 角色档案跨集一致性 + 本地引擎零边际成本 | 用户补充目标（整合本机 ComfyUI/comfy-mini/ACE-Step/Ollama/llama.cpp） |
| 4 | 小白可上手：简单/专业双轨 + 五步创作向导 + 术语白话化 + 引擎就绪度仪表盘 | 用户补充要求（UI 大胆修订，小白快速上手） |
| 5 | 首尾帧衔接分源策略：本地 FL2V 共享边界帧（生成时保证）/ 云端 image_url 条件化 / 库存语义+审查+转场三层 | 方案纠偏（不承诺库存像素连续） |
| 6 | 无头 Playwright 双套件验证 + 五视口截图留证 | doc+demo 迭代惯例 |

**关键约束**：专业模式 opt-in——无方案时走现有快速流水线，行为零变化；Demo 本地引擎为
模拟（状态点可切换在线/离线演示降级），不真调 8188/8001/11434；关键帧/肖像用程序化 SVG
保持离线自包含。

## 3. 验证结果

### 3.1 验证期发现并修复的真实缺陷

1. **portraitSvg 有符号移位崩溃**：`KF_PALETTES[(h >> 3) % len]` 在哈希 ≥2^31 时得负索引
   → undefined 调色板 → 系列角色 tab pageerror。修复：`>>>` 无符号移位。
2. **移动端顶栏挤压项目名**：新模式切换 pill 占用 390px 顶栏宽度，项目名被挤至 0。
   修复：≤760px 隐藏品牌与非激活模式项、语言下拉限宽、topbar gap 收窄。
3. **移动端专业底栏可达性回归**：新底栏丢失音频/视频/字幕页入口。修复：专业模式底栏
   改全量 NAV_ORDER 横向滚动条 + 激活页 scrollIntoView 居中 + 自定义滚动条。
4. **锁定态无法再次生成**：complete 任务 isLocked 拦截 startRun。修复：确认方案生成时
   自动新建草稿项目并重置参数基线，planConfirm 加 data-allow-locked。
5. **en 变体池 CJK 残留**：两处中英混杂文案修复；语言切换后隐藏抽屉旧内容不计入残留扫描。
