## 1. 为什么不能"零代码直接开隧道"（代码中逐一核实的四个拦截点）

| # | 拦截点 | 位置 | 后果 |
|---|---|---|---|
| 1 | `ownHost()` 只认 `127.0.0.1/localhost/[::1]:<port>` | pages.mjs（HTTP/WS/影片三处调用） | 隧道 Host=公网域名 → 全站 403 |
| 2 | 写请求与 WS 升级要求 `Origin === http://127.0.0.1:4747` | server.mjs `authorize()` | 远程浏览器一切写操作 403 |
| 3 | 影片 URL 是绝对地址 `http://localhost:4748/p/<token>/`，内嵌在 API JSON 里 | pages.mjs `folderUrl()` | 远程浏览器加载不了预览；边缘改写无法触及 JSON 体内 URL |
| 4 | bridge/stage 只向单一注入源 postMessage；影片 CORS 单值 | pages.mjs 注入 | 双源桥接在公网下失效 |

**关键约束**：`folderUrl()` 同时喂给**宿主侧 Playwright**（海报/封面/页帧，server.mjs 多处）。这些必须
继续走本地影片源（Access 会拦、hairpin 脆弱）。因此设计为**按请求 Host 切换**：浏览器可见 URL 随 Host
变公网，服务端消费者永远本地。渲染管线（`src/render.mjs`）自带 probe 源，与 pages 服务无关——已核实。

## 2. 变更清单（fork 仓库 `opensources/changovideo`，主题提交 0c8c789…61a54d7 共 9 个）

### 2.1 `feat(studio): public-origin seam for tunneled access`（0c8c789）

新增两个环境变量接缝（沿用 `CHANGOVIDEO_HOME` 等既有惯例），**不设置 = 行为逐字节不变**：
`CHANGOVIDEO_STUDIO_PUBLIC_ORIGIN` / `CHANGOVIDEO_STUDIO_PUBLIC_FILM_ORIGIN`。

- `pages.mjs`：`ownHost(req, port, extraHosts)` 追加精确公网主机名（无端口或 :443）；`startPages` 增加
  `publicFolderUrl`（同 HMAC token、公网基址）；`policy(req)` 按请求回显本地/公网编辑器 Origin（CORS），
  并加 `referrer-policy: no-referrer`（影片 token 不得经 Referer 泄漏）；BRIDGE/STAGE 注入改为 Origin 数组。
- `bridge.js` / `stage.js`：`EDITORS = Array.isArray(__EDITOR__) ? __EDITOR__ : [__EDITOR__]`，post 遍历
  各源（浏览器自动丢弃不匹配的 targetOrigin），消息门 `EDITORS.includes(e.origin)`；字符串形式保持兼容。
- `server.mjs`：两 env 校验（必须 https、无路径/查询/端口异常）；`authorize()` 与 WS 接受本地**或**公网
  Origin（`x-studio-key` 头仍按 CLI 语义跳过 Origin 检查）；新助手 `browserFolder(req, project)` 只用于
  **3 处浏览器可见站点**（saved GET / 项目 GET / history GET），Playwright 站点不动；`/api/health` 增
  `publicOrigin` 标记；公网模式会话 cookie 加 `Secure`；**宿主效应守卫**：公网 Host 拒绝 quit/update/
  open/desktop/pick-folder/pick-files/reveal/locations POST/diagnostics POST/providers billing 等路由；
  `run.json` 保持本地源（CLI 不受影响）。
- `main.mjs`：读取两 env 传入 `startStudio`；**公网模式钉住端口**——4747 被占时记日志并 exit 1，
  不再静默回退随机端口（隧道路由固定，静默换端口会造成难以排查的公网中断）。

## 3. 验证汇总（全部已执行）

1. **基线差分回归**（工作区惯例）：改动前 91 例/86 过/4 败（均为 stage.test.mjs 字体亚像素测量，环境性）；
   改动后同套件 **失败集完全一致，零新增**。`tsc -p studio/server` 与 `-p studio/ui` 均 0 错。
   注意：preview-cache 两例需要 ffmpeg 在 PATH（`opensources/tools`），缺 ffmpeg 时出现的 2 例失败为环境性，非回归。
2. **UI 构建**：`studio/ui/dist` 原缺失（服务器会回"editor is not built"兜底页），vite 构建成功。
3. **本地门禁**：`start.ps1 -SkipTunnel` → 11 项门禁全绿（weclass 与 quick-tunnel 两套源各跑一遍）。
4. **Quick-tunnel 冒烟（两条临时隧道，真实边缘）**：
   - curl 矩阵：影片垃圾 token 404、health 200 带 publicOrigin、无 key 401、带 key 200、
     公网 quit 403、伪造 Origin 写 403、公网 Origin 写 200（项目已清理）、项目 GET 影片 URL 指向公网影片源、
     真实 film.html 公网 200（134 KB）、**本地 Host 仍返回本地影片 URL**。
   - 浏览器实测：深链进入编辑器 → 预览 iframe src 为公网影片源 → 播放走时（00:00→06:28，字幕渲染）→
     控制台零错误（无 CORS/postMessage/混合内容问题）。
   - **WS 事件过公网 wss**：原生 TLS 升级探针（`x-studio-key` 头）101 成功，公网触发 history/save 后
     收到 6 帧实时事件（project/history-progress×3/files/history）。
   - **导出全链路**：公网 POST exports（1 s、24 fps）→ 宿主侧 Playwright+ffmpeg 渲染 24/24 帧完成
     （960 KB mp4）——证明宿主侧渲染不受公网接缝影响；再导出至 Saved 库并经公网
     `GET /api/saved/file` 完整下载 960540 字节（与源文件一致）。导出托盘的 Open/Reveal 属宿主效应，
     公网被守卫拒绝（设计使然）；远程取件走 Saved 库下载，已写入 README。
   - **回归守卫**：停掉两条隧道 → 公网 502，本地编辑器浏览器实测仍完整可用，iframe 自动回到
     `http://localhost:4748/p/...`，播放正常——按请求源设计双向得证。
   - 插曲：quick tunnel 注册 API 在本网络两次超时，第三次成功；影片隧道一次成功。属网络抖动，脚本无需改动。
5. **fail-closed 实证**：Studio 配置 weclass 源时，quick-tunnel Host 的影片请求被 403——未配置即拒绝，
   意外以无 env 方式重启只会造成中断而非泄漏。
6. **public-check.ps1 全矩阵演练**：新增 `-NoAccess` 模式（quick tunnel 无 Access 应用），在临时隧道上
   完整跑通 8 项检查（含认证矩阵：key 门、深链签到、公网影片 URL、伪造/公网 Origin 写、quit 守卫，
   检查项目自动清理）——命名隧道切换日的验证工具已预演完毕。另增 `start.ps1 -VerifyOnly`：对运行中
   实例一键重跑门禁（重启复验铁律的落地命令）。

   - `start.ps1`（token.txt 连接器）11 项门禁全绿；DNS AAAA 已指向 Cloudflare 边缘。
