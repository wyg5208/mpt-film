# 2026-11-20 迭代记录（v1.5.0）：WebUI 三列布局重构与项目参数绑定

本轮迭代将 WebUI 从"顶栏 + 四卡横排 + 预设折叠面板 + 日志"的单页纵向堆叠，重构为
**左导航（11 页）+ 中功能页（底部常驻操作栏）+ 右生成日志** 的三列布局，左右两列可独立收起；
同时落地**任务↔参数绑定**（params.json 快照、顶栏项目切换器、脏检测三选确认、complete 锁定
与另存为新任务）和**预设库**（导入/导出/一键应用）。需求先经方案文档与交互式 HTML demo 验证
（2026-11-19，[三列布局重构需求与方案](../技术栈阶段总结/2026-11-19_MPT三列布局重构需求与方案.md)），
随后按方案 Approach C（**全量渲染 + CSS st-key 显隐壳**）迁入真实 `webui/Main.py`：四个创作渲染器
与生成链路逻辑零改动，AST/i18n/popover 行按钮契约全部保持，浏览器多视口全链路与 pytest 全量
失败集差分双零回归。

版本号按"每次迭代必升版"政策由 `1.4.0` 升至 **`1.5.0`**（minor：新增功能）。

## 1. 任务目标

| # | 目标 | 驱动来源 |
|---|------|---------|
| 1 | 三列布局：左菜单 + 中功能页 + 右生成日志，两列独立收起 | 用户需求（旧四区纵向堆叠层级深、日志区常驻占宽） |
| 2 | 设置子页提升为一级页（LLM/素材/发布渠道/界面），任务管理/发布历史独立页 | 用户需求（设置弹窗 7 tab 层级过深） |
| 3 | 任务↔参数绑定：params.json 快照、加载回填、顶栏项目切换器（20/批 + 加载更多 + 新建空白） | 用户 10 点 v2 需求（换任务丢参数、无法回看历史任务配置） |
| 4 | 脏检测 + 切换三选确认（保存并切换/丢弃并切换/取消）；complete 任务锁定 + 另存为新任务 | 用户 v2 需求（防误覆盖；成片任务参数防篡改） |
| 5 | 预设库：命名保存、JSON 导入导出、一键应用（排除素材类键） | 用户 v2 需求（复用提示词/参数组合） |
| 6 | 零回归迁移 | 方案 Approach C 约束：AST 契约、popover 行按钮契约、参数组装不漂移 |

**关键约束**：`test/services/test_webui_task.py` 以 AST 断言
`_render_generation_controls` 尾语句为 `Return`、`_render_application` 顶层
`generation_submitted` 赋值与 `if not generation_submitted:` 调用集——重构不得触碰生成链路接缝。

  `f"app_shell_n{nav_width}_l{log_width}_m{int(mobile_log_open)}_o{int(log_overlay_user_open)}"`——

## 3. 验证汇总

### 3.1 验证期发现并修复的 4 个真实缺陷

1. **首屏浮层盖顶栏**：`config.ui` 无收起键时日志列默认展开，≤1500px 的 fixed 右浮层
   （top:0/z120）首屏即遮住顶栏项目切换器/设置/语言。修复：761–1500 band 自动竖轨 +
   会话标记 `log_overlay_user_open`（壳键 `_o` 后缀）+ 专用 `log_overlay_open_button`。
2. **竖轨空轨**：`:not(:has([class~=st-key-X]))` 锚不到 `stElementContainer` 自身的键类，
   竖轨按钮全被隐藏；改 `:not([class~=…])` 直接类匹配。
3. **预设保存栏窄屏换行**：水平容器子项 flex-basis:auto + wrap 先换行再收缩；
   改 `flex-wrap:nowrap` + 输入框 `flex:1 1 0`。
4. **任务页惰性渲染破坏 popover 契约**：Phase 2 初版任务管理/发布历史仅激活时渲染，
   headless 回归测试默认 run 寻 `play_task_all_*` → StopIteration。修复：两页改回每次 rerun
   全量渲染（`page_tasks`/`page_publish_history` 容器 + CSS 显隐，与创作页同构）。

（另有几处 harness 侧适配，非产品缺陷：语言后缀前缀选择器、react-aria ComboBox 取值、
固定 sleep 改元素级等待、`waitForSelector` 首匹配被 CSS 隐藏时假超时改 `waitForFunction`。）
