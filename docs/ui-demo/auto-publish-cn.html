🇨🇳 国内平台（免费 · social-auto-upload）
通过本地 social-auto-upload 工具自动发布到抖音、视频号、小红书、B站等平台。 完全免费，需一次性安装并扫码登录（发布使用有头浏览器，仅适合本机桌面部署）。
📦 安装引导（一次性）▼
git clone https://github.com/dreammis/social-auto-upload
cd social-auto-upload
uv venv
uv pip install -e .
copy conf.example.py conf.py
.venv\Scripts\patchright install chromium
GitHub 慢时使用代理源 gitclone.com/github.com/dreammis/social-auto-upload（勿用 Gitee 旧版镜像，缺 sau CLI 与小红书/B站）； 浏览器下载慢可设置 PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright， 镜像 404 时见 docs/auto-publish-cn.md 兜底方案。 安装后在真实终端逐平台扫码登录：sau douyin login --account default。 抖音若触发短信验证，按提示将验证码写入 verify_code.txt。
