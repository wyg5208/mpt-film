新版字标把 ChangoVideo 的「A1 胶片 C 环」与 ChangoFilm 的「霓虹快门 C」直接放到首字母 C 的位置， 后接 hangoVideo / hangoFilm——图标即字母，字母即图标。一枚字标同时完成品牌识别与名称书写， 不再需要「图标 + 全词」的两段式组合。两品牌共享同一套对齐语法，仅保留各自的渐变与字重语义。

结构解析 · 共享对齐语法

mark 不是「摆在文字旁边」，而是按字母排版规则进入文本行：视觉高度取 0.80F， 相对大写字高上下各做约 4% 的光学超出（圆形字母的经典 overshoot），垂直中心对齐字高中心， 右缘与 h 的竖笔保持约 5px 字距。两品牌唯一不同的是 mark 几何与渐变。

ChangoVideo 结构
  • 字号 / 基线：F=56，baseline=70，cap=40.7（Inter 0.727F）
  • mark 高度：44.8 = 0.80F，上越 cap 线 2.1、下越基线 2.0
  • 定位：左缘 x=8；缩放 0.5531（81 单位 → 44.8）
  • 字距：三角右尖 x≈47.8 → 文本起点 x=53
  • 文字语义：整体 700、letter-spacing −1、单色墨（沿用旧版）
ChangoFilm 结构
  • 字号 / 基线：与 Video 完全一致（家族共享语法）
  • mark 高度：44.8 = 0.80F，缩放 0.56（80 单位 → 44.8）
  • 定位：左缘 x=8；叶片右尖 x≈49.8 → 文本起点 x=54
  • 文字语义：hango 600 + Film 800 渐变（浅底品红实色，沿用旧版）
  • 开口朝向：快门缺口与播放三角朝右，天然读作字母 C

尺寸阶梯 · 小至 16px 仍可读

文字合一后不存在独立图标的小尺寸塌陷问题：16px 高度下 mark 与字母同步缩放， C 的开口与播放三角依然可辨，整体按普通字标对待即可。
